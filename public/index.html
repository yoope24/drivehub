Save & Protect Workspace Data

Never lose your folders and Google Drive links

Why does data reset on Render Free Tier?
Free cloud hosting automatically sleeps after 15 minutes of inactivity. When it wakes up, it reloads the project directly from GitHub.

How to save your real ESSU Google Drive links permanently:
  1. Whenever you add or update your folders and links, click "Download Backup (seed_data.json)" below.
  2. Place that file into your project folder under data/seed_data.json.
  3. Run git add .; git commit -m "Save ESSU links"; git push origin main in your terminal.
Once pushed to GitHub, your actual data is permanent and will NEVER reset!
